
# My Portfolio

A personal portfolio website built using React and Vite.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```
